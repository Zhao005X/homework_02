# 这个分支是第二小题
顺带做了选做第四题，与控制思路第一题的思路类似，只是把短按的翻转电平改写为判断led亮度等级，再进行ccr的改写。
## 呼吸灯实现
1.定义变量breath_direction来判断ccr变化方向，0为减少，1为增加
2.当定时器触发中断时，判断breath_direction的值，为1时ccr自增，为0时ccr自减
3.再判断是否达到上下限，如果达到，则改变breath_direction的值来改变ccr变化方向，实现占空比的平滑变化
4.最后输出改变后的pwm，实现呼吸灯的效果
## 舵机旋转
1.原理与呼吸灯相似，但上下限为250和50
2.只有到达上限时，直接将ccr的值写为50
3.每次触发定时器中断时ccr的值自增2，从而实现舵机平滑而合理的速度转动。（1的话我觉得太慢了）
