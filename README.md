# 这个分支是第一小题
在main.c中我通过判断按键状态，按下与抬起所触发的外部中断间所间隔的时间来实现led的开关与控制
## 消抖的实现机制
每次触发中断记录此次中断时间，与上一次中断时间做差，若大于20ms则视为有效中断。由于初始的上次中断时间设置为0，所以第一次也可以正常触发，而按键的抖动不会触发有效中断。由于人按按键的时间不可能小于20ms，所以由于按键抬起而触发的第一次中断也会视为有效中断。
## 按键控制led状态实现
通过每次有效触发中断时进行按键状态的更新，判断按键是否处于按下，并记录按下按键与抬起按键的时间，做差判断是否为长按，实现对led的控制。单独设置一个变量来记录led的状态，判断为长按时再判断led是否处于闪烁状态来判断开启或关闭控制led闪烁的定时器
